## 提交前需人工完成（10 分钟）

1. **封面与分工表**：填写组长/组员姓名、学号、班级、指导教师（封面表格留了下划线空位）。
2. **目录页码**：打开 Word 后 `Ctrl+A` 全选 → 按 `F9`（或右键"更新域"），目录会自动生成/更新页码。
3. **通读一遍第六、八章**：收获体会是以两人协作口吻写的，可按真实感受微调；分工描述按你们的实际分工核对。
4. **文件改名**：提交前把 `报告-班级-姓名.docx` 改成 `报告-你们的班级-你们的姓名.docx`。
